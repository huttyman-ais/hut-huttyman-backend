# hut-huttyman-backend

Node.js + Express API for **hut-huttyman**, generated by the Backstage
`create-application` template.

- **Owner:** user:default/bob
- **Team:** group:default/payments-team
- **Environment:** dev

## Endpoints

| Method | Path | Description |
|---|---|---|
| GET | `/health` | Liveness check |
| GET | `/api/items` | List items from Postgres |
| POST | `/api/items` | Create an item (`{ "name": "..." }`) |

## Local development

```bash
export DATABASE_URL=postgresql://user:pass@localhost:5432/hut-huttymandb
npm install
npm run dev
```

## Deployed configuration

In the DEV environment the connection string is never set as a plain env var — the Container App
reads `KEY_VAULT_URL` and fetches secret `db-connection-string` via its user-assigned managed
identity (see [src/config.ts](../src/config.ts)).
